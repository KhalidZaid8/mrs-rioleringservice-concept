## Lokaal bekijken

Open `index.html` rechtstreeks in een browser of start de meegeleverde previewsserver:

```text
node preview-server.cjs
```

Deze openbare versie is een conceptontwerp, geen officiële website, en bevat `noindex`-instructies voor zoekmachines.
